03 — Research

Active Research
Projects.

Submitted
EDMDc-Based Predictive Control for Real-Time Drone Interception

Applying Extended Dynamic Mode Decomposition with control (EDMDc) to learn a linear Koopman operator representation of nonlinear drone dynamics. The learned model is used within a Model Predictive Control framework to enable real-time interception of autonomous aerial targets with minimal computational overhead.

Explore the project
In Progress
Desensitized i-PID for Precise Motion Control in UAVs

Extending the intelligent PID (i-PID) framework with a desensitization approach to reduce sensitivity to parameter uncertainty and external disturbances. The work targets high-precision motion control for UAV platforms where classical PID tuning is insufficient under varying payload and environmental conditions.

Explore the project
In Progress
Optimal Control for Minimum-Energy Fixed-Wing Flight

Formulating an optimal control problem to minimize battery energy consumption for a fixed-wing UAV relative to a steady-level cruise baseline, exploring throttle and trajectory profiles (e.g. cyclic climb-glide patterns) that reduce total energy draw while still meeting range and time-of-flight constraints.

Explore the project
In Progress
Autonomous Quadcopter for Environmental Water Sampling

A Gulf Scholar project building an autonomous quadcopter that can navigate to a target body of water and collect samples for environmental monitoring. Built on a Pixhawk flight controller paired with a Raspberry Pi companion computer for higher-level autonomy.

In Progress · Open-Source Build
Furuta Pendulum Control Testbed

Building an inverted-pendulum platform as a hands-on controls testbed, using an open-source Arduino design as the hardware starting point. The project connects modeling, sensing, feedback control, and real-time implementation in one physical system.

  • Integrating the actuator, encoder, motor driver, and embedded controller into a complete balancing platform.
  • Using PID control as a baseline for stabilization and tuning while validating the physical model against measured response.
  • Developing the platform as a reusable testbed for more advanced control experiments beyond simulation.

In Progress · Open-Source Build
7-DOF Robotic Arm with Input Shaping

Building a seven-degree-of-freedom robotic arm from an open-source printable design and developing the control stack for smooth point-to-point manipulation with reduced residual vibration.

  • Printing, assembling, and integrating the arm's mechanical joints, actuators, and electronics.
  • Developing joint-space motion and trajectory control for coordinated multi-axis movement.
  • Planning to apply input shaping so the arm can move payloads between locations while suppressing vibration at the end of each maneuver.
